FV_lib est un module boite-à-outils pour lire un fichier gmsh au format ascii 2.0,
pour créer la structure de données nécessaires pour implémenter la méthode des
volumes finis, pour représenter les résultats sous forme graphique.

exécutez le programme principal py_FV_main.py

-----------------------------------------------------------------------------------

The structure of a finite volume project in Python is different from that in Matlab. 
FV_lib is a toolbox module for reading a Gmsh file in ASCII 2.0 format, for creating 
the data structures needed to implement the finite volume method, and 
for displaying the results graphically.

Go to the project directory (for example, 1_sim_square_v1) and 
run the main program py_FV_main.py
