cours de Transfert Thermique Master2 EN

Prerequis pour edition :
1. Installer TexLive ou autre distribution latex
2. Installer le plug-in Iguanatex pour PowerPoint
   https://www.jonathanleroux.org/software/iguanatex/

Prerequis pour certains exercices :
3. Installer une distribution python comme anaconda

Le repertoire pptx contient les presentations.
Le repertoire python contient les programmes python pour les exercices
necessitant un solveur d'équations non lineaires ou un solveur d'équations
différentielles

Le chapitre 4 n'existe pas.
Les chapitres 6 et 7 sont consacres a la methode des volumes finis.
